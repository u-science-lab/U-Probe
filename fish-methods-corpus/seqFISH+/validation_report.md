### Independent results without blocking findings

- Naming and publication: seqFISH+ capitalization/punctuation and the RNA qualifier are supported; the title is not incorrectly used as an acronym expansion. No directory rename is warranted.
- Versions: original RNA preparations, the smFISH comparison and later DNA extensions are distinguished. A boundary-only DNA discussion is not a complete DNA version record, and the corpus does not claim otherwise.
- Architecture/orientation: the primary diagram remains explicitly schematic with unresolved strand order. Readout oligos, manufacturing intermediates and separate anchoring reagents are distinguished. No invented nucleotide string was found. The approximate manufactured length is not turned into an exact spacer specification.
- Target-binding and readout rules: the length, GC, homopolymer, exon fallback, off-target expression burden and cross-hybridization statements agree with the checked Methods. No unsupported reference build, spacing, isoform rule or generic primer string was inserted.
- Barcode calculations: independent XML parsing confirms 3,334/3,333/3,333 gene records for 647/561/488-nm sheets. Within each sheet, all three-position projections are unique while every two-position projection has 400 distinct values. Therefore the minimum four-symbol Hamming distance is 2. The corpus correctly labels this derived and does not promise universal single-substitution correction.
- Readout schedule and decoding: pseudocolour symbols are distinguished from nucleotides and dyes; the QC repeat is distinguished from a new barcoding round. Decoder ambiguity filtering and seed consistency are not misrepresented as an unconditional error-correction guarantee.
- Protocol accuracy: checked values agree with the published-layout Methods. Unusual printed units and solvent wording are explicitly preserved rather than silently repaired. The PMC manuscript abbreviates the solvent as DMF, whereas the retained published-layout text spells it out; the draft's source-specific treatment is acceptable and remains subject to clarification before experimental reuse.
- Public resources and software: codebook assignments, processed measurements, official analysis code and third-party design software are correctly separated. Unconfirmed original design-code availability remains null rather than false. A public codebook does not imply complete synthesized probes.
- References and benchmarks: mouse sample context is supported; unresolved assembly/annotation and sequence details remain explicit. D01 grade C and design-specific D02 grade D are justified by the inspected contents. No A/B ground-truth claim is warranted by these resources. Metadata's aggregate C matches the highest assessed candidate.
- Structural consistency: independent YAML parsing checked duplicate keys, template groups/fields, routing/status agreement, all required Markdown H2 anchors, single H1 headings, local Markdown links and S01–S11 identifiers. No missing required heading or contradictory core numerical value was found. R001 and R003 identify the narrower retrieval issues that remain.
